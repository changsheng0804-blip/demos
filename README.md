# demos · 静态演示页合集

把 changsheng0804-blip 散落的静态演示/测试页面统一收纳到一个仓库，用 GitHub Pages 发布，方便分享给朋友。

## 直接使用“体验驱动意图收敛”技能

本仓库同时是该技能的标准来源，路径为 [技能源目录](.agents/skills/experience-to-intent/)。

在 Codex 对话中发送：

~~~text
$skill-installer 请从 GitHub 仓库 changsheng0804-blip/demos 的路径 .agents/skills/experience-to-intent 安装“体验驱动意图收敛”技能。
~~~

安装后，在新任务中发送：

~~~text
$experience-to-intent 我有一个还说不清的产品想法。请先给我可看、可玩、可比较的小样；不要直接做最终成品。
~~~

不熟悉代码也可以直接使用上面两段话；完整说明和案例见 [先看见，再决定](体验驱动意图收敛-ExperienceToIntent/index.html)。
