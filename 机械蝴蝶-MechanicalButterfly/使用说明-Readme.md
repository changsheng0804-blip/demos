# 机械蝶 · 微光造物

【已确认】这是用 Three.js（三维图形库）制作的可交互机械蝴蝶。全部模型由代码生成，成品页面已内置所需程序，不需要联网、安装软件包或启动服务器。

双击同目录下的 **机械蝶-MechanicalButterfly.html** 即可观看。也可以把这个文件复制到其他电脑，再用浏览器打开。

## 画面与操作

- 四片独立的双面蝶翼、暮紫琉璃镶片、金属翼脉、铆钉、21 组齿轮、分节躯干、触角和发光核心。
- 背面具有独立的分舱翅面、承力筋、导光线、传动结构与背部护架。
- 飞行会交替振翅、舒展和滑翔。前后翼略有错拍，翼尖会弯曲，身体轻微转向和起伏，触角、足部及分节尾部随动作摆动。
- 拖动鼠标旋转，滚轮缩放；手机上用单指旋转、双指缩放。
- 左下角圆形按钮暂停或继续振翅；焦点不在其他按钮或滑块上时，也可以按空格键。
- 默认使用暮紫；三个色点可切换青翡、琥珀与暮紫。
- 两条滑块调节整体动作速度和微光强度。
- “全貌”“近观”“侧影”“背面”切换视角；“复位”恢复默认视角。
- “自动环绕”让镜头围绕蝴蝶旋转。
- “沉浸观赏”隐藏操作面板。按键盘 I 键也可切换，按 Esc（退出键）或“退出沉浸”返回。
- “保存画面”导出当前三维画面的 PNG（常见图片格式）图片，不包含操作面板。

【已确认】启用系统的“减少动态效果”偏好时，页面默认静止，可手动开始振翅。

【不确定】尚未在所有电脑、手机和浏览器上实测性能；运行需要浏览器支持 WebGL 2（浏览器三维图形功能）。

## 文件

- `机械蝶-MechanicalButterfly.html`：独立离线成品，日常使用只需此文件。
- `机械蝶源码-Butterfly.js`：三维模型、动画和操作逻辑。
- `飞行动作-Flight.mjs`：连续飞行动作、振翅节奏与各部件的姿态计算。
- `动作验收-MotionCheck.mjs`：动作幅度、错拍、滑翔及连续性的检查。
- `样式-Style.css`：中文界面的布局和颜色。
- `界面模板-Interface.html`：打包前的页面模板。
- `打包-Build.cjs`：重新生成离线成品的工具。
- `第三方许可-ThirdParty.txt`：Three.js 的开源许可。
- `预览服务-PreviewServer.py`：可选的本机预览服务，普通观看不需要运行。

【建议】直接使用离线成品。只有修改源码时才需要重新打包。当前打包脚本复用同一工作区已安装的 Three.js 0.180.0 和 esbuild（代码打包工具）；换电脑修改时，可通过 `BUTTERFLY_MODULES` 指定这两个软件包所在的目录。

材质实现参考 [Three.js 物理材质官方文档](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)，视角操作参考 [Three.js 轨道控制官方文档](https://threejs.org/docs/pages/OrbitControls.html)。

动作设计参考[隆德大学关于柔性蝶翼的研究介绍](https://www.lunduniversity.lu.se/article/butterfly-wing-clap-explains-mystery-flight)。本作品采用适合观赏的艺术化节奏，没有求解真实气动力。

【建议】如果已经打开旧版页面，请刷新或重新打开成品。修改前的离线页面保存在 `修改前备份-Previous` 文件夹。
